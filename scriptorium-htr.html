EXTRAER LATÍN DE LA IMAGEN · HTR / OCR

**Kraken HTR requiere un servidor con modelo carolingio configurado**. Sin servidor no se puede activar el reconocimiento especializado. Como prueba alternativa, existe OCR latino Tesseract, menos adecuado para manuscritos. Para reconocer una hoja, primero seleccioná su imagen PNG/JPG descargada del visor IIIF; después pulsá el botón grande EXTRAER LATÍN. «Reconocer latín» ejecuta OCR en tu navegador y coloca el resultado en la columna II. Protocolo académico de transcripción

El flujo recomendado es: imagen IIIF → OCR experimental o reconocimiento HTR especializado (externo, con modelo adecuado) → corrección manual → atribución de folio y locus → revisión de variantes. Registrar lecturas dudosas, expansiones de abreviaturas y responsable de cada revisión. Una coincidencia automática no certifica la lectura de un códice.

Guía de instalación del motor HTR: documentación de Kraken para Scriptorium. Las herramientas externas Transkribus y eScriptorium pueden emplearse para pruebas HTR independientes; esta página no ejecuta esos servicios ni envía imágenes a ellos. El OCR experimental utiliza Tesseract.js en el navegador: descarga el motor y los datos lingüísticos, pero no necesita un servidor propio para procesar el folio.
