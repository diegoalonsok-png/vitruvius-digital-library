# Vitruvius Digital Library

Biblioteca académica independiente de acceso gratuito. Proyecto y edición de Diego Kurilo.

Manuscritos, ediciones latinas, traducciones y estudios de De architectura.
Incluye lectura de PDF, búsqueda textual y semántica multilingüe en el navegador,
consulta de dos ediciones en paralelo y exportación de resultados.

Las obras de Diego Kurilo se publican con autorización del autor. Cada fuente
histórica conserva su procedencia y atribución en el catálogo. El permiso de
lectura y descarga no constituye una licencia general para reeditar esas obras.

## GitHub Pages

Publicar desde la rama main, carpeta raíz. No se necesita compilación ni claves.
El modelo gratuito para las búsquedas semánticas se descarga al primer uso.

Los documentos que superan el límite de carga web se conservan en partes
binarias. El visor recompone el archivo original completo, verifica su tamaño
y, cuando el navegador lo permite, su SHA-256. Las descargas entregan el PDF
o DOCX original, sin modificaciones.
